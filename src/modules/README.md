# Módulos

Un módulo por carpeta (catalogo, inventario, compras, ventas, caja, fiado,
comprobantes, reportes). Cada uno contiene sus pantallas, sus llamadas a las
funciones SQL y sus esquemas Zod. Las reglas de negocio NO van aquí: viven en
las funciones SQL de `supabase/migrations/`.

Se crean a partir de la Fase 6.
